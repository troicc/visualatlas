## 已知问题

- **弯箭头搜索慢：** 大分子约 12 秒一张图。跑上千步的基准前必须提速。
- **两端都带标签的键：** 不在链末端时（如 O–B、B–O⁺）画出来太短，需要排版搜索来解决。
- **细节画法：**
  - 溴甲烷这类只有一个碳的取代基，画成一根短线加「Br」，应写成 H₃C–Br；
  - 多出来的旁观物种排列不够整齐。
- **自由基箭头：** 构图合理，但还不够好看。需要作者给出画法标准（参考图，或沿用 2026-10-12 的规则「两根鱼钩在两原子之间碰面，靠近但不相接」）。
- **核对器的限制：** 配位键必须写成电荷分离式；金属只判电子数不超过 18；查不出形式合法、化学上错的步骤。

## 可能做（机器学习相关，待作者决定）

目前项目里没有需要训练的部分。核对是精确逻辑，不该用学习的方法做；排版是规则加搜索。但 LIAC 是做机器学习的组，值得补一个直接对准模型的实验：

| 选项 | 内容 | 成本 | 与 LIAC 的关系 |
| --- | --- | --- | --- |
| A. 测 ChRIMP 已发布的模型（推荐先做） | 用核对器检查他们在 HuggingFace 上发布的机理预测模型的输出：形式不成立的比例、丢失立体中心的比例 | 不用训练；要装 torch，可能要 GPU，先试这台 Mac 能不能跑 | 直接评估他们自己的模型 |
| B. 核对器放进 LLM 循环 | LLM 生成 JSON 格式的机理，核对器把出错的箭头和原子反馈回去，比较几轮之后合法步骤的比例；同时比较 LLM 写 JSON 和写 MechSMILES 的出错率 | 只花 API 费用 | 智能体工作流、LLM 化学基准 |
| C. 用干净数据重新微调 | 用核对器筛掉不成立的步骤，再微调机理预测模型，看效果是否变好 | 需要 GPU，时间长；放到 12 月 20 日之后，作为加分项 | 数据质量对模型的影响 |
